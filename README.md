# Easy Mixamo Rig - downloads

Downloads voor Easy Mixamo Rig: een Blender add-on om Mixamo-animaties op een eigen rig te gebruiken.
Vereist Blender 4.2+ (getest op 5.2).

Alle bestanden staan op de [Releases-pagina](../../releases/latest).

| Bestand | Grootte | Doel |
|---|---|---|
| `easy_mixamo_rig.zip` | 0,1 MB | Blender add-on. Installeren via Edit > Preferences > Add-ons > Install from Disk. |
| `Animatie_Database.zip` | ~50 MB | 379 Mixamo-animaties incl. thumbnails. |
| `Animatie_Database_Rokoko.zip` | ~734 MB | Rokoko free mocap pack, optioneel. Rokoko's eigen voorwaarden zijn van toepassing. Wijs in de animatie-tab het veld 'Extra' folders naar de uitgepakte map. |
| `Handleiding_Easy_Mixamo_Rig.pdf` | 0,2 MB | Handleiding. |
