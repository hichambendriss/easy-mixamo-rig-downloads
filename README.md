# Rigloom - downloads

Rigloom is een Blender add-on: auto-rig, retarget met een klik tussen Mixamo/Rigify/Unity/Unreal/Xsens/Rokoko-rigs, en een animatiedatabase.
Vereist Blender 4.2+ (getest op 5.2).

Alle bestanden staan op de [Releases-pagina](../../releases/latest).

| Bestand | Grootte | Doel |
|---|---|---|
| `rigloom.zip` | 0,1 MB | Blender add-on. Installeren via Edit > Preferences > Add-ons > Install from Disk. |
| `Animatie_Database.zip` | ~50 MB | 379 Mixamo-animaties incl. thumbnails. |
| `Animatie_Database_Rokoko.zip` | ~734 MB | Rokoko free mocap pack, optioneel. Rokoko's eigen voorwaarden zijn van toepassing. Wijs het veld 'Extra' folders naar de uitgepakte map. |
| `Handleiding_Rigloom.pdf` | 0,2 MB | Handleiding. |
