# Rigloom

Rigloom is a Blender add-on: auto-rig a humanoid mesh, retarget with one click between Mixamo / Rigify / Unity / Unreal / Xsens / Rokoko rigs, and an animation database for Mixamo, Rokoko and Xsens clips that work on any of those rigs.
Requires Blender 4.2+ (tested on 5.2).

All files are on the [Releases page](../../releases/latest).

| File | Size | Purpose |
|---|---|---|
| `rigloom.zip` | 136 KB | Blender add-on. Install via Edit > Preferences > Add-ons > Install from Disk. |
| `Animatie_Database.zip` | ~50 MB | Animation Database: 379 Mixamo animations incl. thumbnails. |
| `Animatie_Database_Rokoko.zip` | ~734 MB | Optional Rokoko free mocap pack. Rokoko's own terms apply. Point the 'Extra' folders field in the animation tab at the unzipped folder. |
| `Manual_Rigloom.pdf` | 0.2 MB | Manual (English). |
| `Handleiding_Rigloom.pdf` | 0.2 MB | Manual (Dutch). |
